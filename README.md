# HTML Live Previewer

> Real-time code execution and visual markup rendering playground.

## Overview

A real-time developer sandbox that parses and renders HTML, CSS, and client-side JavaScript in an isolated preview frame with instant live-reloading feedback.

## Key Features

- Split-pane code editor and live sandboxed iframe previewer
- Instant hot-reloading with debounced rendering
- Pre-loaded templates and one-click code reset
- Responsive layout adaptable for side-by-side or stacked orientation

## Architecture and Technology Stack

- **Core Technologies:** Next.js, React, TypeScript, Tailwind CSS, Lucide Icons

## Getting Started

### Prerequisites

Ensure you have the required runtime environment installed for this repository:
- Node.js (v18+) for JavaScript/TypeScript projects
- Python (3.10+) for Python services and agent workflows

### Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/Yusra-Saleem/html-live-previewer.git
cd html-live-previewer
```

Install dependencies:

```bash
# For Node / Next.js projects
npm install

# For Python projects
pip install -r requirements.txt
```

### Running Locally

```bash
# Start local development server
npm run dev

# Or for Python entry points
python main.py
```
